# B组金融时序预测建模总结

## 1. 模型基本原理与功能特性

### 1.1 模型选择

本项目选用 **LightGBM GBT（Gradient Boosting Tree）** 作为主力模型，预测A股股票未来12分钟收益率（fret12）。

### 1.2 数学原理

LightGBM基于梯度提升框架，通过顺序训练多棵决策树来拟合残差：

$$F_m(x) = F_{m-1}(x) + \eta \cdot h_m(x)$$

其中 $F_m$ 为第 $m$ 轮的集成模型，$h_m$ 为第 $m$ 棵决策树，$\eta$ 为学习率（shrinkage）。

每棵树通过最小化当前残差的损失函数来构建：

$$h_m = \arg\min_h \sum_{i=1}^{N} L\left(y_i, F_{m-1}(x_i) + h(x_i)\right)$$

本项目使用L2损失（MSE），残差即为当前预测值与真实值的差。

### 1.3 LightGBM的核心优化

- **直方图加速**：将连续特征离散化为直方图bin（本项目max_bin=63），大幅加速分裂点搜索
- **Leaf-wise生长策略**：按叶子增益分裂而非层级分裂，相同叶子数下精度更高
- **GPU加速**：通过OpenCL接口在NVIDIA RTX 3060上加速直方图计算

### 1.4 适用场景

- **表格数据**：GBT在结构化特征上优于深度学习
- **金融时序预测**：信号弱、噪声大，GBT的加法模型天然适合逐步捕捉微弱模式
- **高维稀疏特征**：特征采样（colsample_bytree）和正则化有效防止过拟合

## 2. 数据处理与特征工程

### 2.1 数据规模

- 训练集：2023年6月1日至11月30日，约123个交易日，约880万样本
- 测试集：2023年12月1日至12月29日，约21个交易日，约144万样本
- 特征维度：54个特征

### 2.2 特征体系（54个特征）

#### 基础特征（6个，5个用横截面rank替换）

| 特征 | 说明 | 处理方式 |
|------|------|----------|
| ob_imb0 | 买一卖一数量不平衡 | → cs_rank_ob_imb0 |
| ob_imb4 | 买1-5档vs卖1-5档不平衡 | → cs_rank_ob_imb4 |
| ob_imb9 | 买5-9档vs卖5-9档不平衡 | → cs_rank_ob_imb9 |
| trade_imb | 主买主卖数量不平衡 | → cs_rank_trade_imb |
| trade_imbema5 | 交易不平衡5期指数平滑 | → cs_rank_trade_imbema5 |
| lagret12 | 过去12分钟超额收益率 | 保留原始值（无量纲） |

#### 价格动量/反转特征（12个，保留原始值）

ret_1, ret_3, ret_6, ret_12, ret_24（多时间尺度收益率），rolling_mean_ret_6/12（趋势方向），rolling_vol_6/12（波动水平），high_low_range（多空争夺），price_position（价格位置），overnight_gap（隔夜跳空）

#### 盘口压力特征（16个，8个用rank替换）

spread, relative_spread, weighted_spread_4, amount_imb_4, depth_sum_4, depth_delta_4, buy_pressure_0, buy_pressure_4, micro_price_dev, bid_ask_bias_0 → 对应cs_rank版本；amount_imb_9/19, depth_sum_9, depth_delta_9, buy_pressure_9, bid_ask_bias_4保留原始值

#### 成交主动性特征（15个，5个用rank替换）

trade_buy_intensity, trade_net_intensity, trade_buy_turnover_ratio, trade_count_imb, buy_trade_size → 对应cs_rank版本；其余10个保留原始值

#### 交互特征（5个，使用rank版本）

- ret_3_x_imb0 = ret_3 × cs_rank_ob_imb0
- ret_6_x_imb0 = ret_6 × cs_rank_ob_imb0
- ret_3_x_buy_intensity = ret_3 × cs_rank_trade_buy_intensity
- spread_x_vol = cs_rank_relative_spread × rolling_vol_12
- highlow_x_imb0 = high_low_range × cs_rank_ob_imb0

### 2.3 横截面rank标准化

对20个与股票规模/流动性相关的特征，在每个时间点做横截面排名：

$$\text{cs\_rank\_X}(i, t) = \frac{\text{rank}(X(i, t))}{N(t)}$$

其中 $i$ 为股票，$t$ 为时间点，$N(t)$ 为该时刻股票总数。结果为0~1的百分位排名。

**设计理由**：
- 消除股票间异质性（大盘股和小盘股的ob_imb0=0.3含义不同）
- 模型学到"相对强弱"而非"绝对值"，泛化更好
- 金融量化研究中的标准操作

### 2.4 缺失值处理

所有缺失值和无穷值填充为0（与eval.py的`replace([inf,-inf],nan).fillna(0)`一致）。

## 3. 超参数调优过程

### 3.1 调参框架

- **算法**：Optuna TPE（Tree-structured Parzen Estimator）贝叶斯优化
- **评估**：3折TimeSeriesSplit时序交叉验证
- **子采样**：每个trial独立随机采样70%数据（sample_ratio=0.7），增加评估鲁棒性
- **提前剪枝**：前2折OverfitRatio < 0.3直接TrialPruned
- **早停**：与learning_rate联动，early_stopping = max(50, 0.1/lr × 50)
- **持久化**：SQLite存储，支持断点续调

### 3.2 搜索空间（V4最终版）

| 参数 | 搜索范围 | 类型 | 说明 |
|------|----------|------|------|
| max_depth | 3~5 | int | 浅树抗过拟合 |
| num_leaves | 7~min(2^max_depth, 63) | int | 受max_depth约束 |
| learning_rate | 0.005~0.1 | float(log) | log均匀采样 |
| n_estimators | 200~2000(step=100) | int | 早停决定实际轮数 |
| subsample | 0.5~0.8 | float | 行采样抗过拟合 |
| colsample_bytree | 0.5~0.8 | float | 列采样抗过拟合 |
| min_child_samples | 50~300(step=50) | int | 叶子最小样本数 |
| reg_alpha | 0.01~2.0 | float(log) | L1正则化 |
| reg_lambda | 0.01~2.0 | float(log) | L2正则化 |

### 3.3 调参迭代过程

| 版本 | 核心改动 | CV Pearson | 测试集Pearson | 问题 |
|------|----------|------------|---------------|------|
| 基线 | 默认参数(depth=3, lr=0.1, n_est=100) | - | 0.0576 | - |
| V1 | categorical搜索空间, 5折CV, 过拟合惩罚 | 0.0577 | 0.0601 | 5折第1折数据太少；lr上限0.05太小 |
| V2 | 连续搜索空间, 3折CV, lr扩展到0.1, 早停联动 | 0.0546 | 0.0553 | 正则化过重导致欠拟合 |
| V3 | 去掉过拟合惩罚, reg上限5→2, min_child上限500→300 | 0.0532 | 0.0606 | CV与正式训练差距大 |
| P1 | 新增20个rank特征(54→74) | 0.0541 | 0.0546 | 原始与rank冗余，colsample被稀释 |
| P1-fix | rank替换原始特征(保持54个) | 0.0579 | 0.0615 | CV首次超基线；leaves=27接近上限 |
| V4 | leaves上限放宽, n_est扩展到2000, 50轮, sample_ratio=0.7 | 0.0583 | **0.0635** | 最终版 |

### 3.4 关键经验教训

1. **过拟合惩罚有害**：金融预测OverfitRatio 0.4~0.6是正常水平，惩罚会让TPE走向极端保守
2. **5折CV第1折数据太少**：20%数据训练Pearson=0.0，污染均值；3折更稳定
3. **子集调参低估模型性能**：sample_ratio=0.5时CV比正式训练低14%；0.7更可靠
4. **特征冗余比缺少特征更糟**：新增rank特征导致colsample稀释，替换策略更优
5. **早停需与lr联动**：lr=0.005时50轮早停太激进，需1000轮

| 均方误差MSE | 0.000026 | **0.000024** | -7.7% |

### 4.2 过拟合分析

- 训练集Pearson: 0.1182

OverfitRatio≈0.5表明模型在训练集上学到的模式约一半能泛化到未见数据，这在金融时序预测中属于正常水平。

## 5. 结果分析与改进建议

### 5.1 当前结果分析

**优势**：
- Pearson从0.0576提升至0.0635（+10.2%），R²从0.00298提升至0.00397（+33.2%）
- 横截面rank标准化有效消除了股票间异质性，是提升的主要来源
- 模型训练稳定，早停机制有效（BestIter=573 << n_estimators=1600）

**劣势**：
- Pearson=0.0635距离目标0.09仍有41.7%的差距
- OverfitRatio=0.493，约一半训练信号无法泛化
- 调参CV评估（0.0583）与测试集评估（0.0635）仍有9%差距，说明调参效率有损失

### 5.2 模型能力边界分析

当前GBT模型在现有54个特征集上，经过4轮调参迭代，Pearson稳定在0.06左右。这表明：
- **特征信息量已接近充分利用**：纯调参在固定特征集上提升有限
- **需要引入新信息源**：从0.06到0.09需要新的信号维度

### 5.3 改进建议

#### P0：滚动统计特征（预期+0.01~0.02）

对核心特征（ob_imb0, trade_imb等）计算滚动均值/标准差/Z-score：
- `ob_imb0_mean_12` = rolling_mean(ob_imb0, window=12)
- `ob_imb0_std_12` = rolling_std(ob_imb0, window=12)
- `ob_imb0_zscore_12` = (ob_imb0 - mean) / std

捕捉特征的时序动量和regime变化，约新增15~20个特征。

#### P1：多股票横截面特征（预期+0.01~0.03）

利用同一时刻所有股票的信息构建横截面特征：
- `cs_ret_rank_3` = ret_3的横截面rank（相对动量排名）
- `cs_vol_rank_12` = rolling_vol_12的横截面rank（相对波动排名）
- `sector_imb_mean` = 同行业ob_imb0均值（行业信号）

#### P2：模型集成（预期+0.005~0.01）

- 训练多个不同seed/不同超参数的GBT模型，取预测均值
- 或尝试DART boosting_type（Dropped trees meet Additive Regression Trees）

#### P3：目标变换（预期+0.005~0.01）

- 对fret12做横截面rank变换后作为目标，预测rank而非原始收益率
- 训练时用rank目标，预测时将rank转回收益率

#### P4：更精细的时序验证（预期+0.005）

- 用全量数据调参（sample_ratio=1.0），牺牲速度换准确度
- 或用Purged TimeSeriesSplit（在训练集和验证集之间加gap，防信息泄漏）

### 5.4 优先级排序

| 优先级 | 改进方向 | 预期Pearson提升 | 实施难度 |
|--------|----------|-----------------|----------|
| P0 | 滚动统计特征 | +0.01~0.02 | 中 |
| P1 | 多股票横截面特征 | +0.01~0.03 | 中 |
| P2 | 模型集成 | +0.005~0.01 | 低 |
| P3 | 目标变换 | +0.005~0.01 | 中 |
| P4 | 精细时序验证 | +0.005 | 低 |

**建议下一步优先实施P0+P1**，这是从0.06到0.09的主要路径。纯调参在固定特征集上已接近天花板，特征工程是突破的关键。
