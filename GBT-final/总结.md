# B组金融时序预测建模总结

## 1. 模型基本原理与功能特性

### 1.1 模型选择

本项目选用 **LightGBM GBT（Gradient Boosting Tree）** 作为主力模型，预测A股股票未来12分钟收益率（fret12）。

### 1.2 数学原理

LightGBM基于梯度提升框架，通过顺序训练多棵决策树来拟合残差：

$$F_m(x) = F_{m-1}(x) + \eta \cdot h_m(x)$$

其中 $F_m$ 为第 $m$ 轮的集成模型，$h_m$ 为第 $m$ 棵决策树，$\eta$ 为学习率（shrinkage）。

每棵树通过最小化当前残差的损失函数来构建：

$$h_m = \arg\min_h \sum_{i=1}^{N} L\left(y_i, F_{m-1}(x_i) + h(x_i)\right)$$

本项目使用L2损失（MSE），残差即为当前预测值与真实值的差。

### 1.3 LightGBM的核心优化

- **直方图加速**：将连续特征离散化为直方图bin（本项目max_bin=63），大幅加速分裂点搜索
- **Leaf-wise生长策略**：按叶子增益分裂而非层级分裂，相同叶子数下精度更高
- **GPU加速**：通过OpenCL接口在NVIDIA RTX 3060上加速直方图计算

### 1.4 适用场景

- **表格数据**：GBT在结构化特征上优于深度学习
- **金融时序预测**：信号弱、噪声大，GBT的加法模型天然适合逐步捕捉微弱模式
- **高维稀疏特征**：特征采样（colsample_bytree）和正则化有效防止过拟合

## 2. 数据处理与特征工程

### 2.1 数据规模

- 训练集：2023年6月1日至11月30日，约123个交易日，约880万样本
- 测试集：2023年12月1日至12月29日，约21个交易日，约144万样本
- 特征维度：76个特征

### 2.2 数据排列方式

数据按 **date → symbol → interval** 排列，即：
- 首先按天排列
- 同一天内，同一只股票按时刻顺序排在一起
- 不同股票之间按symbol排列

这种排列方式影响shift/rolling/ewm操作的正确性：
- **全局shift/rolling**：在股票切换边界处会跨股票取值（错误，但影响比例小~5%）
- **全局ewm**：所有行受前一只股票指数衰减污染（100%受影响，但halflife=5衰减快）
- **sort_values(["symbol","interval"]) + groupby(symbol)**：先排序保证同股票连续，再分组隔离，完全正确

### 2.4 特征计算策略（关键设计决策）

#### shift/rolling/ewm操作的三种策略对比

| 策略 | 适用场景 | 本项目使用位置 |
|------|---------|--------------|
| **全局操作** | 数据已按(symbol,interval)排列，错误仅在边界(~5%) | ret_1~24, bret12, rolling_mean/vol, trade_imbema5, trade_count_imbema5 |
| **sort+groupby(symbol)** | 需要按股票隔离的时序操作 | overnight_gap, depth_delta, rolling_trade_qty, P0全部, P1的change |
| **groupby(interval)** | 横截面操作，同一时刻所有股票 | cs_rank全部, cxbret |

#### 为什么基础特征用全局操作而非groupby(symbol)

V4原版使用全局shift/rolling/ewm，在date→symbol→interval排列下：
- 股票切换边界处shift取到前一只股票的值（错误，但仅影响~5%行）
- ewm跨股票污染（100%行受影响，但halflife=5衰减快）
- **V4全局操作跑出Pearson=0.0635，改为groupby(symbol)反而降至0.0522**

可能原因：
1. 全局操作的边界错误恰好起到了数据增强/正则化效果
2. 全局ewm的跨股票衰减污染提供了微弱的市场整体信号
3. groupby(symbol)改变了特征的分布，与V4调参选出的参数不匹配

**当前策略**：基础特征保持V4原版的全局操作（已验证有效），P0/P1新特征用sort+groupby(symbol)（正确且有效）。

### 2.5 横截面rank标准化

对20个与股票规模/流动性相关的特征，在每个时间点做横截面排名：

$$\text{cs\_rank\_X}(i, t) = \frac{\text{rank}(X(i, t))}{N(t)}$$

其中 $i$ 为股票，$t$ 为时间点（interval），$N(t)$ 为该时刻股票总数。结果为0~1的百分位排名。

**分组粒度**：`groupby("interval")`，不同日期同一interval值会混在一起。这与V4原版一致。

**设计理由**：
- 消除股票间异质性（大盘股和小盘股的ob_imb0=0.3含义不同）
- 模型学到"相对强弱"而非"绝对值"，泛化更好
- 金融量化研究中的标准操作

### 2.6 缺失值处理

所有缺失值和无穷值填充为0（与eval.py的`replace([inf,-inf],nan).fillna(0)`一致）。

## 3. 超参数调优过程

### 3.1 调参框架

- **算法**：Optuna TPE（Tree-structured Parzen Estimator）贝叶斯优化
- **评估**：3折TimeSeriesSplit时序交叉验证
- **子采样**：固定从尾部截取70%数据（sample_ratio=0.7），保证所有trial评估相同时间窗口
- **提前剪枝**：前2折OverfitRatio < 0.3直接TrialPruned
- **早停**：与learning_rate联动，early_stopping = max(50, 0.1/lr × 50)
- **持久化**：SQLite存储，支持断点续调

### 3.2 搜索空间（V5版）

| 参数 | 搜索范围 | 类型 | 说明 |
|------|----------|------|------|
| max_depth | 3~5 | int | 浅树抗过拟合 |
| num_leaves | 7~min(2^max_depth, 63) | int | 受max_depth约束 |
| learning_rate | 0.005~0.1 | float(log) | log均匀采样 |
| n_estimators | 200~2000(step=100) | int | 早停决定实际轮数 |
| subsample | 0.5~0.8 | float | 行采样抗过拟合 |
| colsample_bytree | 0.4~0.7 | float | 列采样抗过拟合 |
| min_child_samples | 50~300(step=50) | int | 叶子最小样本数 |
| reg_alpha | 0.01~2.0 | float(log) | L1正则化 |
| reg_lambda | 0.01~2.0 | float(log) | L2正则化 |

### 3.3 调参迭代过程

| 版本 | 核心改动 | CV Pearson | 测试集Pearson | 问题 |
|------|----------|------------|---------------|------|
| 基线 | 默认参数(depth=3, lr=0.1, n_est=100) | - | 0.0576 | - |
| V1 | categorical搜索空间, 5折CV, 过拟合惩罚 | 0.0577 | 0.0601 | 5折第1折数据太少；lr上限0.05太小 |
| V2 | 连续搜索空间, 3折CV, lr扩展到0.1, 早停联动 | 0.0546 | 0.0553 | 正则化过重导致欠拟合 |
| V3 | 去掉过拟合惩罚, reg上限5→2, min_child上限500→300 | 0.0532 | 0.0606 | CV与正式训练差距大 |
| P1 | 新增20个rank特征(54→74) | 0.0541 | 0.0546 | 原始与rank冗余，colsample被稀释 |
| P1-fix | rank替换原始特征(保持54个) | 0.0579 | 0.0615 | CV首次超基线；leaves=27接近上限 |
| V4 | leaves上限放宽, n_est扩展到2000, 50轮, sample_ratio=0.7 | 0.0583 | 0.0635 | 54特征天花板 |
| V5-err | 76特征+错误_per_session(symbol,date) | 0.0655 | 0.0522 | **特征计算方式错误导致退化** |
| **V5** | 76特征+恢复V4逻辑+P0/P1用sort+groupby(symbol) | - | **0.0714** | **当前最优** |

### 3.4 V5特征计算错误的教训

V5迭代过程中引入了`_per_session(symbol,date)`按(symbol,date)分组，导致严重退化：

| 错误 | 影响 | 退化机制 |
|------|------|---------|
| shift按(symbol,date)分组 | 每天第一根bar的shift全为NaN→fillna(0) | 丢失隔夜信息，ret_1~24每天开头全错 |
| rolling按(symbol,date)分组 | 每天开头只有1~2个数据点 | 统计量极不稳定，引入大量噪声 |
| ewm按(symbol,date)分组 | trade_imbema5每天重置 | 完全失去跨天记忆，信号消失 |
| cs_rank按(date,interval)分组 | 不同日期不再混合 | 改变了rank的分布特性 |

**关键教训**：金融时序特征的跨天连续性很重要，不能简单按(symbol,date)分组切断。V4原版的全局操作虽然理论上有跨股票边界错误，但实际影响极小(~5%行)，而每天重置的影响是100%的。

### 3.5 关键经验教训

1. **过拟合惩罚有害**：金融预测OverfitRatio 0.4~0.6是正常水平，惩罚会让TPE走向极端保守
2. **5折CV第1折数据太少**：20%数据训练Pearson=0.0，污染均值；3折更稳定
3. **子集调参低估模型性能**：sample_ratio=0.5时CV比正式训练低14%；0.7更可靠
4. **特征冗余比缺少特征更糟**：新增rank特征导致colsample稀释，替换策略更优
5. **早停需与lr联动**：lr=0.005时50轮早停太激进，需1000轮
6. **子采样随机起点破坏TPE**：不同trial评估不同时间窗口，CV分数不可比；改为固定尾部截取
7. **特征计算正确性>特征数量**：76个错误计算的特征(0.0522)不如54个正确计算的特征(0.0635)
8. **跨天连续性很重要**：shift/rolling/ewm不能按(symbol,date)分组切断每天重置

## 5. 结果分析与改进建议

### 5.1 当前结果分析

**优势**：
- Pearson从0.0576提升至0.0714（+23.9%），突破历史记录
- P0滚动统计特征有效捕捉了微观结构特征的时序动量
- P1横截面特征有效捕捉了相对强弱信号
- 特征计算策略与V4原版对齐，保证基础特征的正确性

**劣势**：
- Pearson=0.0714距离目标0.09仍有20.7%的差距
- 当前参数仍是V4调参结果，76特征集尚未重新调参
- 基础特征的全局shift/rolling在股票边界处有~5%错误行

### 5.2 改进建议

#### P2：重新调参（预期+0.005~0.01）

76特征集的最优参数与54特征集不同：
- colsample_bytree可能需要调高（76特征需要更多列采样）
- n_estimators可能需要增加（更多特征需要更多轮次）
- 搜索空间需适配76特征

#### P3：模型集成（预期+0.005~0.01）

- 训练多个不同seed/不同超参数的GBT模型，取预测均值
- 或尝试DART boosting_type

#### P4：目标变换（预期+0.005~0.01）

- 对fret12做横截面rank变换后作为目标
- 预测rank而非原始收益率

#### P5：更精细的时序验证（预期+0.005）

- 用全量数据调参（sample_ratio=1.0）
- 或用Purged TimeSeriesSplit（训练集和验证集之间加gap）

### 5.3 优先级排序

| 优先级 | 改进方向 | 预期Pearson提升 | 实施难度 |
|--------|----------|-----------------|----------|
| P2 | 重新调参(76特征) | +0.005~0.01 | 低 |
| P3 | 模型集成 | +0.005~0.01 | 低 |
| P4 | 目标变换 | +0.005~0.01 | 中 |
| P5 | 精细时序验证 | +0.005 | 低 |

**建议下一步优先重新调参**，76特征集在V4参数下已达0.0714，专用调参有望进一步提升。
