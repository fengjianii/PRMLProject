二、B的具体任务分解

基于“按天安排”和具体流程描述，B的任务可按时间顺序分解如下：

Day 1: 项目启动与基线建立

1.  跑通初始代码：确保项目入口 python meow.py 能够成功运行，不报错。
2.  复现 Ridge Baseline：运行初始代码，复现出作为基准的Ridge回归模型结果。
3.  记录初始指标：计算并记录Baseline模型的三个核心评估指标：MSE (均方误差)、Pearson Correlation (皮尔逊相关系数) 和 R² (决定系数)。
4.  明确运行方式：梳理并记录项目的代码结构和数据路径，确保团队后续工作基于此稳定环境。

Day 2: 模型训练与迭代实验

1.  训练主力模型：使用A构造的特征，训练性能更强的主力模型，文档推荐的选项包括：
    ◦   LightGBM

    ◦   XGBoost

    ◦   MLP (多层感知机)

    ◦   或 sklearn 中的 HistGradientBoostingRegressor、RandomForestRegressor。

2.  进行特征组合对比实验：按照文档建议的顺序，系统地评估不同特征组合对模型性能的影响：
    ◦   实验0: 原始Baseline (Ridge)

    ◦   实验1: Baseline + 价格类特征

    ◦   实验2: 实验1 + 盘口（订单簿）类特征

    ◦   实验3: 实验2 + 成交（市场事件）类特征

    ◦   实验4: 全部特征 + 主力（非线性）模型

3.  计算与记录指标：对每一次实验，都计算并保存 MSE、Pearson、R² 三个指标。
4.  防止过拟合检查：在模型训练和评估过程中，采取措施（如使用验证集、早停法、观察训练/验证曲线）避免模型过拟合。
5.  输出最终预测结果：使用确定的最佳模型和特征组合，在整个训练集上重新训练（或在测试集上预测），生成最终的 predicted_fret12 序列，并交付给成员C用于后续的Agent策略。

    ◦   实验结果部分：清晰展示从Baseline到最终模型的指标对比表，说明每一步新增特征或更换模型带来的性能变化。
