### 3. Baseline模型详解

#### 3.1 模型架构
**当前Baseline使用Ridge回归（L2正则化线性回归）**
- **模型类型**：线性回归 + L2正则化
- **正则化参数**：alpha=0.5
- **特征数量**：6个基础特征
- **训练数据**：2023年6月1日 - 2023年11月30日（约123个交易日，880万样本）
- **测试数据**：2023年12月1日 - 2023年12月29日（约21个交易日，144万样本）

#### 3.2 当前使用的6个特征
1. **ob_imb0** - 买一卖一不平衡
   - 公式：`(asize0 - bsize0) / (asize0 + bsize0)`
   - 含义：反映最及时的价格压力信号

2. **ob_imb4** - 买1-5档vs卖1-5档不平衡
   - 公式：`(asize0_4 - bsize0_4) / (asize0_4 + bsize0_4)`
   - 含义：考虑更深档位的买卖力量对比

3. **ob_imb9** - 买5-9档vs卖5-9档不平衡
   - 公式：`(asize5_9 - bsize5_9) / (asize5_9 + bsize5_9)`
   - 含义：远档位订单反映长期意图

4. **trade_imb** - 主买主卖数量不平衡
   - 公式：`(tradeBuyQty - tradeSellQty) / (tradeBuyQty + tradeSellQty)`
   - 含义：主买多说明买方主动，价格上涨概率大

5. **trade_imbema5** - 交易不平衡的指数平滑
   - 公式：`EWM(trade_imb, halflife=5)`
   - 含义：平滑短期波动，捕捉趋势

6. **lagret12** - 过去12分钟超额收益率
   - 公式：`bret12 - cx_bret12`
   - 含义：个股相对市场的超额收益，反映动量/反转效应

#### 3.4 模型训练细节
**训练流程：**
1. **数据加载**：从H5文件读取分钟级股票数据
2. **特征生成**：基于原始数据计算6个特征
3. **模型训练**：使用Ridge回归拟合特征与fret12的关系
4. **模型预测**：在测试集上进行预测
5. **结果评估**：计算MSE、Pearson、R²三个指标

**模型公式：**
```
min ||y - Xw||² + alpha * ||w||²
```
其中：
- `y`：目标变量fret12（12分钟后的forward return）
- `X`：特征矩阵（6个特征）
- `w`：模型权重
- `alpha=0.5`：正则化强度参数
