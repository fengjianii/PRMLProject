# GBT模型实验记录

## 实验概述
**实验目标**：将原始Ridge线性回归模型替换为LightGBM GBT（梯度提升树）模型，使用54个扩展特征，提升预测性能至Pearson 10%以上

**执行时间**：2026年5月31日  
**执行人**：B组成员  
**代码位置**：`B/GBT/`文件夹

## 一、模型配置

### 1.1 模型参数（防过拟合设计）
```python
# LightGBM GBT参数配置
params = {
    # 基础参数
    'objective': 'regression',
    'metric': 'l2',
    'boosting_type': 'gbdt',
    'verbose': -1,
    
    # 防过拟合参数
    'max_depth': 3,           # 限制树深度
    'num_leaves': 8,          # 叶子节点数（2^max_depth）
    'min_child_samples': 20,  # 叶子节点最小样本数
    'min_child_weight': 1e-3, # 叶子节点最小权重和
    
    # 采样参数
    'subsample': 0.8,         # 样本采样比例
    'colsample_bytree': 0.8,  # 特征采样比例
    'subsample_freq': 1,      # 采样频率
    
    # 正则化参数
    'reg_alpha': 0.0,         # L1正则化
    'reg_lambda': 1.0,        # L2正则化
    
    # 学习参数
    'learning_rate': 0.1,     # 学习率
    'n_estimators': 100,      # -\u6811\u7684\u6570\u91cf（带早停）
    
    # 其他参数
    'random_state': 42,       # 固定随机种子
    'n_jobs': -1,             # 使用所有CPU核心
}

# 早停机制
early_stopping_rounds = 10
```

### 1.2 特征配置
**特征总数**：54个（原始6个 + 新增48个）

**特征分类**：
1. **基础特征**（6个）：订单簿不平衡、交易不平衡、超额收益
2. **价格动量/反转特征**（12个）：不同时间尺度收益率、波动率、价格位置
3. **盘口压力特征**（16个）：价差、深度、不平衡、微观价格
4. **成交主动性特征**（15个）：成交强度、比例、滚动统计、笔数
5. **交互特征**（5个）：动量×盘口、流动性×波动等

## 三、特征重要性分析

### 3.1 Top 10重要特征
基于训练过程中的特征重要性（gain）排序：

1. **overnight_gap** (0.4300) - 隔夜跳空
   - **金融含义**：隔夜信息对开盘的冲击
   - **重要性**：最高，说明隔夜信息对短期预测最关键

2. **ret_24** (0.3511) - 24分钟收益率
   - **金融含义**：较长期价格动量
   - **重要性**：次高，说明24分钟尺度动量效应显著

3. **rolling_vol_12** (0.2318) - 12窗口波动率
   - **金融含义**：近期价格波动水平
   - **重要性**：高波动往往伴随交易机会

4. **spread_x_vol** (0.1884) - 价差×波动率交互
   - **金融含义**：流动性紧张×高波动的复合效应
   - **重要性**：交互特征进入前5，验证了非线性关系

5. **lagret12** (0.0709) - 过去12分钟超额收益
   - **金融含义**：个股相对市场的超额收益
   - **重要性**：动量/反转效应的核心指标

6. **ret_12** (0.0554) - 12分钟收益率
   - **金融含义**：与预测目标时间尺度一致的历史收益

7. **rolling_trade_sell_qty_12** (0.0344) - 12窗口主卖成交量
   - **金融含义**：近期卖压强度
   - **发现**：卖压比买压更有预测力

8. **trade_imbema5** (0.0310) - 交易不平衡指数平滑
   - **金融含义**：平滑后的买卖力量趋势

9. **ret_3_x_buy_intensity** (0.0308) - 短期动量×买方力度
   - **金融含义**：动量与买方主动性的交互

10. **ret_6** (0.0194) - 6分钟收益率

## 五、与目标差距分析

### 5.1 当前成绩：Pearson = 5.76%
**已达成**：
- ✅ 相比Baseline提升159.5%
- ✅ 相比特征工程后的Ridge提升114.1%
- ✅ 证明了非线性模型的有效性

**与目标10%的差距**：4.24个百分点

### 5.2 差距原因分析

#### 5.2.1 模型层面
1. **参数未调优**：使用默认参数，未进行网格搜索
2. **树数量有限**：n_estimators=100（带早停）
3. **学习率固定**：learning_rate=0.1，未使用衰减

#### 5.2.2 特征层面
1. **特征标准化缺失**：未进行Z-score或MinMax标准化
2. **特征选择未做**：54个特征中可能存在冗余
3. **时序特征不足**：缺少滞后项、移动平均等
4. **市场状态特征**：未加入市场宽基、板块轮动

#### 5.2.3 数据层面
1. **噪声问题**：金融数据信噪比低
2. **非平稳性**：市场状态随时间变化
3. **数据泄漏风险**：需要严格的时间序列分割

### 5.3 达到10%的优化路径

#### 5.3.1 立即优化（预计+2-3个百分点）
1. **特征标准化**：Z-score标准化所有特征
2. **特征选择**：使用Lasso或随机森林筛选Top 20特征
3. **参数调优**：网格搜索学习率、树深度、叶子数

#### 5.3.2 中期优化（预计+1-2个百分点）
4. **时序特征**：添加滞后特征、滚动统计
5. **交互特征扩展**：尝试更多特征组合
6. **模型集成**：LightGBM + XGBoost + CatBoost

#### 5.3.3 高级优化（预计+1-2个百分点）
7. **市场状态特征**：添加市场宽基收益率
8. **板块轮动**：行业因子、市值因子
9. **深度学习**：LSTM/Transformer时序模型
