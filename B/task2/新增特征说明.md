# 新增特征说明文档

## 概述
在原始6个特征的基础上，新增了48个特征，总共54个特征。这些特征分为5大类：
1. **基础特征**（6个）：原有的订单簿和交易不平衡特征
2. **价格动量/反转特征**（12个）：捕获不同时间尺度的价格变化模式
3. **盘口压力特征**（16个）：衡量买卖双方的力量对比和流动性
4. **成交主动性特征**（15个）：分析交易行为的强度和方向
5. **交互特征**（5个）：捕捉特征间的非线性关系

## 一、价格动量/反转特征（12个）

### 1. 历史收益率特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| ret_1 | (midpx(t) - midpx(t-1)) / midpx(t-1) | 1分钟收益率，捕捉极短期动量 |
| ret_3 | (midpx(t) - midpx(t-3)) / midpx(t-3) | 3分钟收益率，短期趋势 |
| ret_6 | (midpx(t) - midpx(t-6)) / midpx(t-6) | 6分钟收益率，中期趋势 |
| ret_12 | (midpx(t) - midpx(t-12)) / midpx(t-12) | 12分钟收益率，与预测目标时间尺度一致 |
| ret_24 | (midpx(t) - midpx(t-24)) / midpx(t-24) | 24分钟收益率，较长期趋势 |

### 2. 滚动统计特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| rolling_mean_ret_6 | ret_1在6窗口内的均值 | 近期趋势方向——往上还是往下 |
| rolling_mean_ret_12 | ret_1在12窗口内的均值 | 中期趋势方向 |
| rolling_vol_6 | ret_1在6窗口内的标准差 | 近期波动水平——波动大的时候往往有交易机会 |
| rolling_vol_12 | ret_1在12窗口内的标准差 | 中期波动水平 |

### 3. 价格区间特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| high_low_range | (high - low) / midpx | 区间内多空争夺的剧烈程度 |
| price_position | (lastpx - low) / (high - low) | 收盘价在区间内的位置，接近高点说明买方占优 |
| overnight_gap | (open - prev_close) / prev_close | 隔夜信息对开盘的冲击，仅首分钟有效 |

## 二、盘口压力特征（16个）

### 1. 价差特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| spread | ask0 - bid0 | 绝对价差，单位是元 |
| relative_spread | (ask0 - bid0) / midpx | 相对价差，跨股票可比 |
| weighted_spread_4 | (vwap_ask_4 - vwap_bid_4) / midpx | 加权价差，考虑各档深度的spread |

### 2. 金额不平衡特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| amount_imb_4 | (atr0_4 - btr0_4) / (atr0_4 + btr0_4) | 1-5档金额不平衡——钱在哪边 |
| amount_imb_9 | 同amount_imb_4（9档数据暂用4档替代） | 1-9档金额不平衡 |
| amount_imb_19 | 同amount_imb_4（19档数据暂用4档替代） | 1-19档金额不平衡 |

### 3. 深度特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| depth_sum_4 | bsize0_4 + asize0_4 | 1-5档总深度，深度越大流动性越好 |
| depth_sum_9 | 同depth_sum_4（9档数据暂用4档替代） | 1-9档总深度 |
| depth_delta_4 | depth_sum_4(t) - depth_sum_4(t-1) | 深度变化速度——有人在吃单还是挂单 |
| depth_delta_9 | depth_sum_9(t) - depth_sum_9(t-1) | 9档深度变化 |

### 4. 买方压力特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| buy_pressure_0 | bsize0 / (bsize0 + asize0) | 买一档压力，>0.5说明买方更多 |
| buy_pressure_4 | bsize0_4 / (bsize0_4 + asize0_4) | 1-5档买方压力 |
| buy_pressure_9 | 同buy_pressure_4（9档数据暂用4档替代） | 1-9档买方压力 |

### 5. 微观结构特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| micro_price_dev | (micro_price - midpx) / midpx | 微观价格偏离：订单权重价 vs 简单中间价 |
| bid_ask_bias_0 | (bid0×bsize0 - ask0×asize0) / (bid0×bsize0 + ask0×asize0) | 价格和数量双加权的买卖偏向（买一卖一） |
| bid_ask_bias_4 | (btr0_4 - atr0_4) / (btr0_4 + atr0_4) | 1-5档金额偏向 |

## 三、成交主动性特征（15个）

### 1. 成交强度特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| trade_buy_intensity | tradeBuyQty / depth_sum_4 | 主买成交量占盘口深度的比例 |
| trade_sell_intensity | tradeSellQty / depth_sum_4 | 主卖成交量占盘口深度的比例 |
| trade_net_intensity | (tradeBuyQty - tradeSellQty) / depth_sum_4 | 净成交量强度 |

### 2. 成交额比例特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| trade_buy_turnover_ratio | tradeBuyTurnover / (btr0_4 + atr0_4) | 主买成交额占挂单额的比例 |
| trade_sell_turnover_ratio | tradeSellTurnover / (btr0_4 + atr0_4) | 主卖成交额占挂单额的比例 |
| trade_net_turnover_ratio | (tradeBuyTurnover - tradeSellTurnover) / (btr0_4 + atr0_4) | 净成交额比例 |

### 3. 滚动成交量特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| rolling_trade_buy_qty_6 | tradeBuyQty在6窗口内滚动求和 | 近期主买成交活跃度 |
| rolling_trade_buy_qty_12 | tradeBuyQty在12窗口内滚动求和 | 中期主买成交活跃度 |
| rolling_trade_sell_qty_6 | tradeSellQty在6窗口内滚动求和 | 近期主卖成交活跃度 |
| rolling_trade_sell_qty_12 | tradeSellQty在12窗口内滚动求和 | 中期主卖成交活跃度 |

### 4. 成交笔数特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| trade_count_imb | (nTradeBuy - nTradeSell) / (nTradeBuy + nTradeSell) | 成交笔数的不平衡 |
| trade_count_imbema5 | trade_count_imb的EMA(halflife=5) | 平滑后的成交笔数不平衡趋势 |

### 5. 单笔成交大小特征
| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| buy_trade_size | tradeBuyQty / nTradeBuy | 主买单笔平均成交量——大单还是小单 |
| sell_trade_size | tradeSellQty / nTradeSell | 主卖单笔平均成交量 |
| trade_size_ratio | buy_trade_size / sell_trade_size | 买卖单笔大小比——哪边更大手笔 |

## 四、交互特征（5个）

| 特征名 | 计算方式 | 金融含义 |
|--------|---------|---------|
| ret_3_x_imb0 | ret_3 × ob_imb0 | 短期动量 × 盘口不平衡——方向一致性 |
| ret_6_x_imb0 | ret_6 × ob_imb0 | 中期动量 × 盘口不平衡 |
| ret_3_x_buy_intensity | ret_3 × trade_buy_intensity | 动量 × 买方力度 |
| spread_x_vol | relative_spread × rolling_vol_12 | 流动性紧张 × 高波动 |
| highlow_x_imb0 | high_low_range × ob_imb0 | 剧烈争夺 × 盘口偏向 |

## 五、特征生成注意事项

### 1. 数据列检查
代码中已添加对缺失数据列的检查：
- 如果缺少`tradeSellQty`、`tradeSellTurnover`、`nTradeSell`等列，相关特征会设为0或使用替代值
- 9档和19档数据暂时使用4档数据替代

### 2. 缺失值处理
- 所有特征计算都包含除零保护（`.replace(0, 1e-10)`）
- 最终特征矩阵使用`.fillna(0)`填充缺失值
- 滚动计算使用`min_periods=1`确保有值

### 3. 计算性能优化
- 按股票分组进行滚动计算，避免跨股票数据污染
- 使用向量化操作，避免循环
- 特征计算顺序优化，减少重复计算

## 六、金融含义总结

### 价格动量特征
- **短期收益率**（ret_1, ret_3）：捕捉极短期价格变化，反映市场即时反应
- **中期收益率**（ret_6, ret_12）：捕捉趋势持续性，识别动量或反转效应
- **波动率**（rolling_vol）：衡量价格不确定性，高波动往往伴随交易机会
- **价格位置**（price_position）：反映当前价格在区间内的相对强弱

### 盘口压力特征
- **价差类**：衡量市场流动性和交易成本
- **深度类**：反映市场深度和挂单意愿
- **不平衡类**：识别买卖力量对比
- **微观价格**：捕捉订单簿的加权价格信息

### 成交主动性特征
- **强度类**：衡量交易对盘口的冲击程度
- **趋势类**：识别成交活动的持续性
- **大小类**：分析交易者行为模式（大单 vs 小单）

### 交互特征
- **动量×盘口**：当价格趋势与盘口力量一致时，信号更强
- **流动性×波动**：高波动+低流动性往往意味着更大的价格冲击
- **区间×偏向**：宽幅波动时的盘口偏向更有信息量

## 七、后续优化建议
